# The original web prototype

This is the first version of what is now Anneal: a single-page, no-build, local-only web app
for body dysmorphia, written before the React Native app in the root of this repository.
`README.md` beside this file is that prototype's own README and still calls the product
**Steady**, which was its name at the time. That is correct and should not be "fixed" — it is
an archived artefact, not a live surface, and rewriting the name in it would make the history
of the rename harder to read rather than easier.

## Why it is here rather than where it was

It lived in `Borntosoar/soar-brand`, the repository for an unrelated clothing brand run by the
same person. That is the linkage `docs/DIRECTION.md` §4 argues against: an app for body
dysmorphia should not be discoverable from an apparel brand's repository, because the
association is exactly the one this product cannot afford and cannot undo once made.

`soar-brand` is private, so this was never a live exposure — but the app did not belong there
either way, and leaving it meant the separation depended on a repository setting staying
unchanged forever.

## What it is worth

Not much as code — the React Native app supersedes it entirely. It is kept because it is the
only copy of the earliest form of the protocol, and because keeping it here means
`soar-brand` can have its history purged later without losing anything.
